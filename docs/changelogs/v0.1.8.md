This release fixes install reliability and cold-start issues.

## Improvements

- Claude Code provider profiles moved into `data/providers.toml` with load-time validation. Operator-facing config is unchanged.

## Bug fixes

- The opencode installer treats a failed script fetch as a failure, so a stale binary can no longer pass the post-install check.
- The ACP `initialize` timeout is raised from 15s to 60s to cover cold first launches on freshly provisioned hosts.
