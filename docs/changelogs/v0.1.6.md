This release lets `acps init serve` bound its own lifetime and fixes several agent-install issues.

## Hosted init

- `acps init serve` now self-terminates abandoned sessions: `--idle-timeout` (default `15m`; `0s` disables) cancels the session after a stretch with no connected WebSocket client and no API activity, and `--max-lifetime` (disabled by default) caps the absolute server lifetime regardless of activity. A WebSocket disconnect restarts the idle clock, so a dropped backend gets the full timeout to reconnect. Session status snapshots include `last_activity_age_secs` so the hosting backend can make its own reap-vs-wait decisions.

## Agent installs

- npm harnesses that print an array version output no longer fail version detection.
- npm-prefix pi installs are linked into the managed bin directory so the installed binary resolves.
- Install-path failures now return enumerated, actionable errors instead of a generic failure.
- GitHub API calls during install are paced to avoid rate-limit failures.

## Release pipeline

- Only the x86_64 artifact is published to the releases service.
