This release lets hosted init bound its own lifetime and fixes several agent-install issues.

## Features

- `acps init serve` self-terminates abandoned sessions via `--idle-timeout` and `--max-lifetime`.

## Improvements

- Only the x86_64 artifact is published to the releases service.

## Bug fixes

- npm harnesses that print array version output no longer fail version detection.
- npm-prefix pi installs link into the managed bin directory so the installed binary resolves.
- Install-path failures return enumerated, actionable errors.
- GitHub API calls during install are paced to avoid rate-limit failures.
