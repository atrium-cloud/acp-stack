This release runs Kimi Code on most catalog providers, adds a separate workload user for agents, numbers session events with a change feed, and installs a managed Node.js runtime.

## Breaking changes

- Hosted init clients must close the discovery phase with `close_discovery` (or `POST /v1/init/sessions/{id}/discovery/close`) once discovery finishes. A run that issued a discovery prompt waits for the close and is cancelled at the idle timeout.
- The hosted init start request returns `400` for MCP declarations against an existing config, and for starter-only declarations against one unless `resume` is set.
- Removed provider ids: `azure-openai-responses` (use `azure`), `kimi-for-coding` (use `kimi-coding`), `fw` (use `fireworks`), and the OpenCode providers `bailing`, `firepass`, `github-models`, and `v0`.
- `acps init` replaces an agent CLI that acp-stack did not install, including CLIs installed by earlier releases, with the pinned version or the latest release. Pass `--existing-agent use-existing` to keep one. An ACP adapter acp-stack did not install is always replaced.
- `acps serve` downloads Node.js 26 from nodejs.org, and the Docker image and the systemd and VM installers no longer ship Node. A host that cannot reach nodejs.org reports `node` as `failed` on `/v1/health/ready`, and the Pi and Hermes installs need Node on `PATH`.
- `[agent].command` and `[agent.install].creates` must be an absolute path or a bare command name.
- A `stalled` prompt is no longer final: the agent's later result replaces it and records a `prompt.stall_resolved` event.
- Sessions move from `active` to `available` after 30 seconds idle (`[sessions].idle_threshold`) and when the agent stops or exits or the daemon restarts. `available` sessions still take prompts, and the status route no longer reports `available` as a derived `state`.
- `GET /v1/sessions/{id}/events` answers an unknown `after` cursor with `404 session.event_cursor_unknown`; re-read the snapshot for a fresh cursor. Deleted sessions answer `410 session.deleted` for 30 days.
- `/v1/ws` closes a subscriber that falls more than 1024 events behind with code `1013`. Reconnect and read the missed events from the event log; `acps logs query --follow` does this itself, and `acps logs tail` exits non-zero.

## Features

- Kimi Code runs every catalog provider marked for it, including OpenAI, Anthropic, OpenRouter, DeepSeek, Z.AI, MiniMax, and OpenCode Zen and Go.
- Native config import for Kimi Code and Hermes Agent, plus Claude Code `settings.local.json`.
- `acps agent switch` changes the current agent's provider or model in place, and `--model` (`model` on `POST /v1/agent/switch`) commits a model with any switch.
- Hosted init discovery answers stay revisable until the client closes the discovery phase.
- `[workspace.sandbox].workload_user` runs the agent, its terminals, and mediated commands as a separate local user, with workspace and config file I/O under that user's credentials.
- `[workspace.sandbox].mask_files` hides individual files and sockets from the sandbox, and `require_network_provider` refuses spawns without a network provider.
- A managed Node.js 26 runtime for agents, installers, and dependency installs. The Pi and Hermes recipes, Standard Setup, and the Docker, systemd, and VM images no longer install Node themselves.
- Agent CLI version pins through `acps init --agent-version`, honored on npm installs and managed updates, and `--existing-agent` to keep or replace a CLI acp-stack did not install.
- Session events carry a `seq` position for paging (`after_seq`), and `GET /v1/sessions/-/changes` is a change feed covering session edits and deletions.
- Breakpoint forks on the Claude Code and Codex adapters, and forks carry the parent's history up to the fork point.
- The session event log records the accepted user prompt, finished client terminals (`terminal.finished`), and end-turn token usage (`prompt.usage_reported`).
- OpenCode runs on Azure OpenAI and Kimi For Coding (Global).
- `[logging].acp_trace` logs every ACP frame between the daemon and its agents.

## Improvements

- `acps agent test` picks its own session mode and retries the next advertised mode on mode-caused failures (`--one-shot` opts out), removes its test file afterwards, and classifies provider rejections in its JSON output, now `schema_version` 3.
- Model pickers list ACP-advertised models in the agent's order with its display names, and discovery probes apply the requested model (`GET /v1/models?model=`) so per-model efforts match.
- A prompt for a session the running agent has not opened re-attaches it through `session/resume` or `session/load` first.
- `POST /v1/agent/update` stops an idle running agent for the update and starts it again afterwards.
- An agent switch that names a provider restarts the agent, starting it if stopped, so a changed stored credential takes effect.
- Turns with an open tool call get a longer stall threshold (`[prompts].tool_call_stale_threshold`, default 1 hour).
- Every response carries an `x-request-id`, failed requests log once under it, agent stderr reaches the daemon log, and every log line is redacted.
- Error envelopes carry the agent's redacted JSON-RPC error in `details.acp_error`, and public error messages leave out local paths, I/O error text, and subprocess output.
- A workspace write through a symlink inside the workspace replaces the linked file instead of being refused, and downloads stream without the `max_file_bytes` cap.

## Bug fixes

- Hermes Agent selects Hermes' own provider ids, so the OpenAI lane reaches `openai-api` instead of failing as an unknown provider.
- OpenCode on Kimi For Coding uses models.dev's current `kimi-code-plan-cn` id.
- Pi installed from its GitHub release unpacks the whole bundle, so the binary finds its bundled files.
- A provider switch removes the previous provider's env refs and active entry.
- A managed-state namespace can move its endpoint override to another provider.
- Errors without a code mapping return `server.internal_error` instead of panicking.
- The Meta provider lists models from `api.meta.ai`.
- rustls is updated for RUSTSEC-2026-0285.
