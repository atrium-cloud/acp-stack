This release makes `acp-stack` a full ACP client: agents can run shell commands and edit workspace files through the daemon.

## Features

- Client terminals: agents run commands through the daemon under the sandbox profile, recorded in the durable command log with live event streaming.
- Client filesystem: agents read and write workspace files through the daemon, confined to the session workspace and audited.
- Agent shell activity is filterable in `acps logs`, including activity from agents still on their built-in tools.

## Improvements

- The Supabase mirror upgrades in place on setup re-runs, keeping mirrored data and the stored writer password.
