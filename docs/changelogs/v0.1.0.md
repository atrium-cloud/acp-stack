Initial release of `acp-stack`, a self-hostable Linux runtime for ACP-compatible agents.

## Features

- ACP protocol v1 runtime with one configured agent, durable SQLite state, session create/load/resume/fork, and prompt streaming over WebSocket.
- Array mode: multiple agent targets under a single runtime, with a primary target backing the default surfaces.
- Supported agents: Claude Code, Codex CLI, OpenCode, Pi Agent, Goose, Amp Code, and Cursor CLI.
- Agent skills install, ACP subagent wiring, and a pluggable agent sandbox.
- Encrypted secret storage with secret references in config; plaintext never written to config.
- Tiered API keys, permission review for mediated commands, rate limits, and a security self-check.
- Guided setup with `acps init` and a portable TOML config with full export/import round-trip.
- Workspace file browse/upload/download and mediated shell commands.
- Local SQLite logging with live WebSocket events, plus an optional Supabase analytics mirror.
- Stack self-update with release manifest verification.
- Single-binary Linux distribution (`x86_64`/`aarch64`), install script, Docker image, and systemd units.
