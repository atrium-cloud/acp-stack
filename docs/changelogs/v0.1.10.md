This release adds Agent Skills management, on-demand agent updates, and three new supported agents.

## Breaking changes

- The wire spelling of `canceled` is now `cancelled` across statuses, events, and decision reasons. Stored state migrates automatically; clients matching the old strings must update.
- `POST /v1/agent/switch` renames the request field `agent` to `agent_id` and returns model objects instead of plain strings.
- Native-config error codes now carry the `agent.` prefix.
- Hosted init streams `signal` events in place of the `state` frame; clients fold the stream into their own state.
- Codex with OpenAI authenticates with a stored API key; the Codex-native auth lane is removed.
- Cursor CLI support is removed.
- Several provider API-key names changed; re-store the affected secrets (see docs/specs/agents/api_key.md).

## Features

- Day-2 Agent Skills management: `acps skills` commands, matching API routes, and configurable skill sources.
- On-demand agent updates with per-component version status, plus init flags to decline auto-update.
- New supported agents: Kilo Code, Kimi Code, and Google Antigravity, each verified end-to-end.
- Per-session slash commands: list and run the agent's advertised commands.
- Per-provider endpoint overrides through managed-state credential apply.
- Initial session mode selection at init (`acps init --mode`).
- JSON Schema for the `/v1` API and config, published with every release.
- Live install progress via the installer-runs API.

## Improvements

- Agent switches are journaled and resumable; retries are safe.
- A dependency apply no longer blocks other API requests while it runs.
- Provider catalogs expanded across Hermes, pi, and opencode.
- Claude Code third-party provider profiles updated to current models.
- Hosted init prompts are machine-readable with stable answer values.
- Registry entries can declare custom ACP launch arguments.

## Bug fixes

- A pinned harness version constrains managed updates, matching install behavior.
- Codex rejects an invalid double-qualified OpenRouter model slug at init instead of failing silently at prompt time.
- Timed-out install steps report their captured output, and registry shell installs honor per-run timeouts.
