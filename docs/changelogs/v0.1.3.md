This release upgrades the ACP SDK to 1.2.0 and tightens protocol conformance.

## Improvements

- The bridge speaks the SDK's native shapes, sends `clientInfo`, and requires protocol version 1 at initialize.
- Prompt content types and MCP transports are gated on the agent's advertised capabilities.
- Standard `usage_update` and `session_info_update` notifications are normalized alongside the legacy shapes older agents emit.
- Stdio MCP commands resolve to absolute paths before crossing the ACP boundary.
- `GET /v1/metrics/summary` reports the peak context-window usage in the requested window.

## Bug fixes

- A pending permission decision no longer blocks the ACP event loop; other updates keep flowing while it waits.
- Protocol cancellation atomically cancels a still-pending permission request.
