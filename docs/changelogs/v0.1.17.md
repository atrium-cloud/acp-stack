## Features

- Pi's launch env carries `PI_ACP_PROVIDER_MODELS`, a JSON object of each endpoint's Pi provider id and the model ids its keyed listing returned for the row's key, for `pi-acp` to list only the models the key is offered. An `_acpStack/launch_env` push sets it in `env`, or names it in `unset` when no endpoint lists models. Declaring it in `[agent].env` or `workload_env` is rejected.

## Bug fixes

- A Pi default slot with no model on a row with several endpoints starts sessions on a model its key can use: Pi's settings name the first model the default endpoint's keyed listing returned as `defaultModel` beside `defaultProvider`, since Pi ignores `defaultProvider` without one. A model Pi does not know leaves Pi on its built-in default.
