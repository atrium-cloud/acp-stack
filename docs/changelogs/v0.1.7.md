This release adds secret-reference templates in config values and moves hosted environment configuration into the session-create request.

## Features

- Config value positions accept `${SECRET_REF}` templates, so one secret composes into several values; pure literals are still rejected.
- Hosted init accepts the full environment configuration in the create request, replacing the interactive environment wizard for hosted clients.
- `acps init --rotate-keys` regenerates both API keys in place.
- Interactive init offers masked entry for declared MCP and data-source secret refs missing from the store.

## Improvements

- HTTP MCP URLs may be plain http toward a loopback host.
- An invalid MCP declaration no longer fails daemon startup; it is skipped with a warning.
- Hosted init always rotates keys, so the result frame always carries them to the backend.
- Create-route validation rejects unknown fields and validates secret positions up front.

## Bug fixes

- Installer subprocesses run detached and non-interactive, so vendor installers that prompt on a tty no longer hang init.
- An init failure before key handover parks the session with a retrievable typed error instead of dying unreadably.
