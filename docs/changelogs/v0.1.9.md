This release makes capability handling probe-first, adds Hermes Agent, and introduces live provider model catalogs.

## Features

- Hermes Agent is a supported native harness with headless provisioning.
- Live provider model catalogs: providers can declare a models URL, and `GET /v1/models` serves the fetched list.
- `POST /v1/sessions/{id}/delete` forwards ACP session deletion when the agent supports it.
- Nightly releases: `scripts/release.sh` defaults to tagging prereleases, with no version commit or changelog required.

## Improvements

- Init runs a handshake-only capability probe after install, so capability queries answer before the first real agent start.
- Configured features the agent does not advertise are skipped and reported as ignored instead of erroring.
- Session routes lazily start a stopped agent instead of answering `agent.not_running`.
- Installed agent binaries are validated at install time; failing binaries are reinstalled.
- Third-party provider profiles refreshed to current models.
- The ACP SDK is bumped to 1.3.0.

## Bug fixes

- A pending permission request no longer outlives its mediated command.
- npm agent installs allow package lifecycle scripts, which npm 12 otherwise blocks into a stub binary.
- `acps agent test` auto-approves permission requests, making it safe non-interactively.
