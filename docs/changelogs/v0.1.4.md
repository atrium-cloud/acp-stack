This release introduces the extensions framework: typed integration seams declared as `[extensions.<name>]` config and fulfilled by external software.

## Breaking changes

- `[workspace.sandbox.network]` no longer loads; declare an extension with `type = "network-provider"` instead. The provider fields carry over unchanged.

## Features

- Extension type `network-provider`: per-spawn network namespaces whose policy belongs to an external provider executable, deny-all by default.
- Extension type `managed-state`: an external orchestrator owns a named state namespace through a single admin apply route, with revision ordering and store-level ownership.
- `acps extensions status` reports declared instances.
