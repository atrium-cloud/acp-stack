## Features

- `[workspace.sandbox].workload_env` and `workload_path_prepend` declare environment variables and leading `PATH` directories for the agent, its terminals, and mediated commands, such as a pre-built Python venv. Advertised as the `sandbox-workload-env` feature.
- `ACPS_PROVIDER_HTTP_PROXY`, when set, sends provider-keyed requests such as the model-catalog fetch through that HTTP proxy, loopback destinations excepted. Advertised as the `provider-http-proxy` feature.
- `provider_check: true` on the hosted init start request parks the run for the discovery close, then checks the credential with one real turn on the chosen model and reports the verdict as a `provider_check` signal, parking again on a failure. Advertised as the `init-provider-check` feature.
