This release generalizes per-session ACP config options, extends reasoning-effort selection across more agents, adds operator-designated adapters, and hardens hosted init.

## Breaking changes

- The Claude Code agent id changes from `claude-code` to `claude`. Update any `[agent] id`, `POST /v1/agent/switch` body, and provider-key reference that named `claude-code`.
- The auth tier `bootstrap` is renamed `init` in the published schema (`$defs/AuthTier`) and the hosted-init routes. Clients keying off the tier name must update.

## Features

- Generic per-session ACP config options: the `[agent.config_options]` map, `GET /v1/agent/config-options`, and `GET`/`POST /v1/sessions/{id}/config-options`.
- Reasoning-effort selection for opencode, pi, goose, Kimi Code, and Kilo Code, plus goose mode selection.
- Operator-designated ACP adapters through `[agent.adapter_override]`, launching a registry agent under a custom adapter while its harness install and updates stay managed.
- `[permissions].acp_prompt_action = "approve"` answers an agent's own permission requests as they arrive, for unattended operation.
- Background dependency apply via `--deps-apply-async`, with durable run tracking and polling routes.
- Machine-readable `acps agent test` JSON output, plus hosted provider-credential deferral (`--defer_provider_credentials`).
- Origin-only endpoint overrides with vendor base URLs for every mapped provider.
- OpenRouter reasoning efforts provisioned for Codex and opencode from the provider catalog.
- Hosted init gains a bootstrap-tier `GET /v1/models`, a REST input twin (`POST /v1/init/sessions/{id}/input`), in-stream credential deposit (`POST /v1/init/credential`), and `[extensions]` plus sandbox mask paths in the create body.

## Improvements

- Hermes Agent runs through the hermes-agent-acp adapter, and pi through atrium-cloud/pi-acp, with Node install mechanics for atrium-cloud adapters.
- Amp aligns with amp-acp v0.9 model and mode config options.
- Init prompts for and persists generic ACP session config options, and reports the settled agent selection on the handoff payload.
- Session modes apply from the native ACP modes lane via `session/set_mode`.
- The capability snapshot embeds agent and adapter install versions.
- goose model discovery reads the provider catalog and gates its probe spawns.

## Bug fixes

- Cancel settles a session as `cancelled` and its pending ACP permissions, and rejects a concurrent in-flight prompt.
- Argv-less terminal create commands run through the workspace shell.
- Hosted-init durable rows settle when a step fails or panics.
- The Hermes native env override lane is honored.
