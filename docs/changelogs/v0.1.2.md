This release adds native harness-config import, a provider credential catalog, network-isolated sandboxing, and session file-change snapshots.

## Features

- Fail-closed network isolation for sandboxed spawns, with policy delegated to an operator-supplied provider executable.
- `acps agent config inspect|import`: review and import an existing harness config as a journaled transaction, with secrets and executable settings guarded.
- Provider credential catalog with named aliases (`acps agent provider credential`), and multi-active providers on harnesses that support it.
- `GET /v1/sessions/{id}/changes`: a bounded snapshot of the file changes the agent reported.
- Kimi Code wired as a native agent; headless support is pending an upstream auth fix.

## Improvements

- Skill catalogs index per-skill instead of plugin bundles, and gain several new reviewed sources.
- Standard Setup installs a curated set of essential skills.
